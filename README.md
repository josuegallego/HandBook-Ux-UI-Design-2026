# UX/UI Design Handbook 2026 · Flipbook

Versión interactiva tipo libro del **UX/UI Design Handbook 2026**, una guía para quienes quieren empezar en UX/UI: qué habilidades desarrollar, qué herramientas aprender, dónde formarse, qué cargos existen, cuánto se gana y hacia dónde va la profesión.

## Cómo verlo

Abre `index.html` en cualquier navegador moderno. Es un solo archivo con las 16 páginas incluidas; solo necesita internet para cargar la animación de páginas y las tipografías.

Para publicarlo en la web: **Settings → Pages → Branch: `main` / root**. GitHub lo servirá en `https://<usuario>.github.io/HandBook-Ux-UI-Design-2026/`.

## Qué incluye

- Efecto de página real con tapas duras en portada y contraportada; el libro cerrado queda centrado y se desliza al abrirse.
- Vista de dos páginas en escritorio y de una página en celular.
- Índice y contraportada clicables, y los enlaces de las fuentes activos.
- Panel de miniaturas, barra de progreso y enlace directo a cada página (`#pagina-10`).
- Modo "Leer de cerca" con zoom para leer en el celular.
- Sonido de página (se puede silenciar), modo claro/oscuro y navegación con teclado (← →, Inicio, Fin).
